# Campos personalizados

Los programas pueden tener campos personalizados para almacenar información adicional.

## Configuración

Se accede desde **Administración del sitio > Cursos > Currículo > Campos personalizados del programa**.

Desde ahí se pueden crear categorías y campos usando el sistema estándar de campos personalizados de Moodle.

## Permiso requerido

Se necesita la capacidad `local/curriculum:configurecustomfields` para acceder a esta configuración.
